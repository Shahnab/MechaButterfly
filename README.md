# The Morphing Machine — 0621-RN (MechaButterfly)

Interactive 3D mechanical butterfly kinetic architecture with custom shaders, WebGL rendering, articulated wing morphing, and real-time rotation and speed controls.

Live Demo: [https://shahnab.github.io/MechaButterfly/](https://shahnab.github.io/MechaButterfly/)

## Features

- **Kinematic Simulation**: Articulated wing mechanics with multi-joint wing kinematics and real-time telemetry.
- **Custom Shaders**: Procedural textures, holographic/carbon-fiber/titanium material passes, and lighting.
- **Interactive HUD & Dock**: Full telemetry readouts, rotation controls, speed modulation, and display modes.

## Getting Started

### Prerequisites

- Node.js 18+ (Node 22 recommended)
- npm or bun

### Installation

```bash
git clone https://github.com/Shahnab/MechaButterfly.git
cd MechaButterfly
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```

## Deployment

Automated deployments are handled via GitHub Actions to GitHub Pages on every push to the `main` branch.
